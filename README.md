## 🪁 Now building: [Kiteloom](https://kiteloom.com)

Kiteloom is my startup: **an infinite canvas where sketches, wireframes and diagrams are the same object**, so an idea never has to be exported into another tool to become a finished file. It is live at [kiteloom.com](https://kiteloom.com).

- Real-time multiplayer on Yjs CRDTs, with a local copy that reconciles after a dropped connection
- Arrows bind to a shape's edge, so diagrams re-route instead of breaking when you move things
- Private by default, revocable share links, and exports on every plan, including free
- Next.js · TypeScript · Convex · Yjs · shipped in 11 languages

## Featured projects

### 📱 [Edgepad](https://github.com/akshit-bansal11/edgepad) &nbsp;![Stars](https://img.shields.io/github/stars/akshit-bansal11/edgepad?style=flat-square) ![Release](https://img.shields.io/github/v/release/akshit-bansal11/edgepad?style=flat-square)

Turns an Android phone into a trackpad, media remote and control panel for a Windows laptop, over a direct Bluetooth link: **no account, no Wi-Fi, no cloud.** It has corner-dial volume and brightness, multi-finger gestures, drawn-shape macros, an on-screen keyboard and a gamepad that drives a real virtual Xbox controller.
<br>`Kotlin` `C# / .NET 10` `Bluetooth RFCOMM` · [Docs](https://edgepad-docs.vercel.app) · [Download](https://github.com/akshit-bansal11/edgepad/releases/latest)

### 🔐 [Lokey](https://github.com/akshit-bansal11/lokey)

A local-only encrypted vault for passwords, env keys and backup codes on Windows. It has **no network code at all**, and its content security policy forbids every connection. It uses Argon2id and AES-256-GCM, and every release ships with SHA-256 checksums and a signed build attestation, so you can verify the exe you run.
<br>`Rust` `Tauri` `TypeScript` · [Download](https://github.com/akshit-bansal11/lokey/releases/latest)

### 🧰 [Open Tools](https://github.com/akshit-bansal11/open-tools)

35+ privacy-first browser utilities for media, PDF, SVG, CSS and color. Everything runs client-side and nothing is uploaded: a free alternative to paid tool sites.
